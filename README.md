# permutations

Permutation groups for Maxima, built on Robert Smith's
[cl-permutation](https://github.com/stylewarning/cl-permutation). Proof of
concept; SBCL only.

Maxima's `combinatorics` package works on single permutations. This package
adds groups: order, membership, subgroups, normal subgroups, orbits and
element lists, computed with cl-permutation's Schreier–Sims implementation.

## Install

The package isn't in the mxpm index yet, so install it from a checkout:

```bash
mxpm install --path /path/to/permutations --editable
```

mxpm installs cl-permutation and its dependencies through Quicklisp
(`mxpm setup quicklisp` if you don't have it yet). Then, in Maxima:

```maxima
load("permutations")$
```

## Permutations

A permutation is a list of images, the same form the `combinatorics`
package uses: `[2,1,3]` maps 1 to 2, 2 to 1 and 3 to 3. Lists of
different lengths are padded with fixed points.

Composition reads right to left, as in Dummit and Foote §1.3:
`pgrp_compose(s, t)` is s∘t, which applies `t` first. So
(1 2 3)∘(1 2)(3 4) = (1 3 4). This is the opposite of `combinatorics`'
`permult`: `permult(p, q)` equals `pgrp_compose(q, p)`.

## Functions

### Permutations

| Function | Result |
|---|---|
| `pgrp_compose(s, t, ...)` | s∘t∘..., the last argument applied first |
| `pgrp_inverse(p)`, `pgrp_power(p, k)` | the inverse; p composed with itself k times (k may be negative) |
| `pgrp_identity(n)` | the identity of degree n |
| `pgrp_cycles(p)` | disjoint cycles, 1-cycles left out, each starting at its least point |
| `pgrp_from_cycles(cycles, [n])` | the product of the cycles, right to left: `pgrp_from_cycles([[1,2],[1,3]])` is (1 2)∘(1 3) |
| `pgrp_element_order(p)` | the order of p, the lcm of its cycle lengths |
| `pgrp_sign(p)` | 1 if p is even, -1 if odd |
| `pgrp_cycle_type(p)` | all cycle lengths, 1-cycles included, largest first |

### Named groups

| Function | Group |
|---|---|
| `pgrp_cyclic(n)` | Z_n, generated by (1 2 ... n) |
| `pgrp_dihedral(n)` | D_2n, the symmetries of an n-gon, as in D&F §1.2: r = (1 2 ... n) and s, the reflection fixing vertex 1 (n ≥ 3) |
| `pgrp_symmetric(n)` | S_n, generated by (1 2) and (1 2 ... n) |
| `pgrp_alternating(n)` | A_n, generated by (1 2 k) for k = 3, ..., n |
| `pgrp_quaternion()` | Q_8 on itself by left multiplication; points 1, ..., 8 stand for 1, -1, i, -i, j, -j, k, -k, and the generators are i and j |

### Groups

| Function | Result |
|---|---|
| `pgrp(p_1, ..., p_k)` or `pgrp([p_1, ..., p_k])` | the group generated by the `p_i` |
| `pgrp_p(x)` | whether `x` is a permutation group |
| `pgrp_degree(G)` | the number of points `G` acts on |
| `pgrp_generators(G)` | the generators, padded to the degree |
| `pgrp_order(G)` | the number of elements |
| `pgrp_member_p(G, p)` | whether `p` is in `G` |
| `pgrp_subgroup_p(H, G)` | whether `H` is a subgroup of `G` |
| `pgrp_normal_p(H, G)` | whether `H` is a normal subgroup of `G` |
| `pgrp_orbits(G)` | the orbits on 1, ..., degree |
| `pgrp_random(G)` | a uniformly random element |
| `pgrp_elements(G)` | all elements in lexicographic order, up to `pgrp_max_elements` (default 100000) |
| `pgrp_cayley_table(G or list, [labels])` | the Cayley table as a matrix: row a, column b holds a∘b, labelled 1, 2, ... or with the labels given; fails if the list isn't closed |

## Example

```maxima
(%i1) load("permutations")$
(%i2) S4 : pgrp([2,1,3,4], [2,3,4,1]);
(%o2)            pgrp(degree 4, 2 generators)
(%i3) A4 : pgrp([2,3,1,4], [1,3,4,2])$
(%i4) [pgrp_order(S4), pgrp_order(A4), pgrp_normal_p(A4, S4)];
(%o4)                    [24, 12, true]
(%i5) pgrp_member_p(A4, [2,1,3,4]);
(%o5)                         false
```

The tests also build the Rubik's cube group from cl-permutation's README
and check its order, 43252003274489856000.
