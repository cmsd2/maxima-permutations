# permutations

[![Docs](https://img.shields.io/badge/docs-online-blue)](https://cmsd2.github.io/maxima-permutations/)

Permutation groups for Maxima, built on Robert Smith's
[cl-permutation](https://github.com/stylewarning/cl-permutation). Proof of
concept; SBCL only.

Maxima's `combinatorics` package works on single permutations. This package
adds groups: order, membership, subgroups, normal subgroups, orbits and
element lists, computed with cl-permutation's Schreier–Sims implementation.

The [documentation](https://cmsd2.github.io/maxima-permutations/) has every
function with examples. After `load("permutations")`, `? pgrp_compose` and
the like show the same entries in Maxima.

## Install

The package isn't in the mxpm index yet, so install it from a checkout:

```bash
mxpm install --path /path/to/permutations --editable
```

mxpm installs cl-permutation and its dependencies through Quicklisp
(`mxpm setup quicklisp` if you don't have it yet). Then, in Maxima:

```maxima
load("permutations")$
```

## Permutations

Functions return permutations as `pgrp_perm` values, shown in cycle
notation:

```maxima
(%i2) pgrp_elements(pgrp_symmetric(3));
(%o2)            [(), (2 3), (1 2), (1 2 3), (1 3 2), (1 3)]
```

Every function also accepts a list of images, the form the `combinatorics`
package uses: `[2,1,3]` maps 1 to 2, 2 to 1 and 3 to 3. `pgrp_perm([2,1,3])`
turns one into the other and `pgrp_perm_list(p)` turns it back. Lists of
different lengths are padded with fixed points.

A `pgrp_perm` keeps its degree, so (1 2) in S_4 has cycle type [2, 1, 1].
Equal permutations of the same degree are the same value, so `=`, `member`,
`unique` and `setify` work on them. `pgrp_eq` compares permutations of
different degrees, or a `pgrp_perm` with a list. `string(p)` gives
`pgrp_perm([...])`, which reads back as p, and `tex(p)` gives the cycles.

Set `pgrp_perm_output : false` to get lists of images back instead.

Composition reads right to left, as in Dummit and Foote §1.3:
`pgrp_compose(s, t)` is s∘t, which applies `t` first. So
(1 2 3)∘(1 2)(3 4) = (1 3 4). This is the opposite of `combinatorics`'
`permult`: `permult(p, q)` equals `pgrp_compose(q, p)`.

## Functions

### Permutations

| Function | Result |
|---|---|
| `pgrp_compose(s, t, ...)` | s∘t∘..., the last argument applied first |
| `pgrp_inverse(p)`, `pgrp_power(p, k)` | the inverse; p composed with itself k times (k may be negative) |
| `pgrp_identity(n)` | the identity of degree n |
| `pgrp_cycles(p)` | disjoint cycles, 1-cycles left out, each starting at its least point |
| `pgrp_from_cycles(cycles, [n])` | the product of the cycles, right to left: `pgrp_from_cycles([[1,2],[1,3]])` is (1 2)∘(1 3) |
| `pgrp_element_order(p)` | the order of p, the lcm of its cycle lengths |
| `pgrp_sign(p)` | 1 if p is even, -1 if odd |
| `pgrp_cycle_type(p)` | all cycle lengths, 1-cycles included, largest first |
| `pgrp_conjugate(x, g)` | the conjugate g x g⁻¹ |
| `pgrp_commutator(x, y)` | [x, y] = x⁻¹y⁻¹xy, the identity exactly when x and y commute |
| `pgrp_fixed_points(p)` | the points p doesn't move |
| `pgrp_perm(l)`, `pgrp_perm_p(x)` | the permutation with image list l; whether x is a `pgrp_perm` |
| `pgrp_perm_list(p, [n])` | the image list of p, padded with fixed points to length n if given |
| `pgrp_apply(p, i)` | the image of the point i; points past the degree are fixed |
| `pgrp_support(p)` | the points p moves |
| `pgrp_eq(p, q)` | whether p and q are the same permutation, ignoring degree |
| `pgrp_sort(l)` | the permutations in l in order of their image lists |
| `pgrp_degree(p)` | the degree of p |

### Named groups

| Function | Group |
|---|---|
| `pgrp_cyclic(n)` | Z_n, generated by (1 2 ... n) |
| `pgrp_dihedral(n)` | D_2n, the symmetries of an n-gon, as in D&F §1.2: r = (1 2 ... n) and s, the reflection fixing vertex 1 (n ≥ 3) |
| `pgrp_symmetric(n)` | S_n, generated by (1 2) and (1 2 ... n) |
| `pgrp_alternating(n)` | A_n, generated by (1 2 k) for k = 3, ..., n |
| `pgrp_quaternion()` | Q_8 on itself by left multiplication; points 1, ..., 8 stand for 1, -1, i, -i, j, -j, k, -k, and the generators are i and j |

### Groups

| Function | Result |
|---|---|
| `pgrp(p_1, ..., p_k)` or `pgrp([p_1, ..., p_k])` | the group generated by the `p_i` |
| `pgrp_p(x)` | whether `x` is a permutation group |
| `pgrp_degree(G)` | the number of points `G` acts on |
| `pgrp_generators(G)` | the generators, padded to the degree |
| `pgrp_order(G)` | the number of elements |
| `pgrp_member_p(G, p)` | whether `p` is in `G` |
| `pgrp_subgroup_p(H, G)` | whether `H` is a subgroup of `G` |
| `pgrp_normal_p(H, G)` | whether `H` is a normal subgroup of `G` |
| `pgrp_orbits(G)` | the orbits on 1, ..., degree |
| `pgrp_random(G)` | a uniformly random element |
| `pgrp_elements(G)` | all elements in lexicographic order, up to `pgrp_max_elements` (default 100000) |
| `pgrp_cayley_table(G or list, [labels])` | the Cayley table as a matrix: row a, column b holds a∘b, labelled 1, 2, ... or with the labels given; fails if the list isn't closed |
| `pgrp_cayley_graph(G, [gens])` | the Cayley graph as `[n, edges]`: vertex i is the i-th of `pgrp_elements(G)`, and edge `[i, j, k]` joins g_i to g_i∘s_k; a generator of order 2 gives each edge once |
| `pgrp_spectral_layout(C, [dim])` | a point in `dim` dimensions (default 3) for each vertex of a graph `[n, edges]`, from its Laplacian's eigenvectors; draws a Cayley graph with the group's symmetry |

Most functions below work by listing elements, so they refuse groups with
more than `pgrp_max_elements` elements. `pgrp_order`, `pgrp_member_p`,
`pgrp_orbits` and `pgrp_stabiliser_chain` don't list elements and work on
large groups. Functions that return groups return `pgrp` handles of the
same degree as the group they came from.

### Actions and counting

| Function | Result |
|---|---|
| `pgrp_from_action(gens, points, act)` | the permutation group on 1, ..., n induced by `gens` acting on the list `points` through `act(g, x)`; point i stands for `points[i]`. `gens` can be matrices, permutations or anything `act` accepts |
| `pgrp_action_perm(g, points, act)` | the permutation of the points that one element induces |
| `pgrp_orbit(G, x)`, `pgrp_stabiliser(G, x)` | the orbit of point x; the subgroup fixing it |
| `pgrp_count_orbits(G, k)` | colourings of the points with k colours up to G (Burnside's lemma); k may be a symbol |
| `pgrp_cycle_index(G, [x])` | the cycle index as a polynomial in `x[1]`, `x[2]`, ... |
| `pgrp_colouring_orbits(G, k)` | one colouring (a list of colours, one per point; not a permutation) from each orbit, the least in each; as many as `pgrp_count_orbits(G, k)` |
| `pgrp_regular(G)` | Cayley's theorem: G acting on its elements (in `pgrp_elements` order) by left multiplication |

### Homomorphisms and isomorphisms

| Function | Result |
|---|---|
| `pgrp_hom(G, H, images)` | the homomorphism sending `pgrp_generators(G)` to `images`; fails if they define none |
| `pgrp_hom_apply(phi, p)`, `pgrp_hom_p(x)` | the image of p; whether x is a homomorphism |
| `pgrp_kernel(phi)`, `pgrp_image(phi)`, `pgrp_preimage(phi, K)` | subgroups of the source, target and source |
| `pgrp_isomorphism(G, H)` | an isomorphism, or `false`, found by search |
| `pgrp_isomorphic_p(G, H)` | whether G ≅ H |
| `pgrp_order_profile(G)` | [order, count] pairs: how many elements have each order |
| `pgrp_sign_hom(G)` | the sign homomorphism onto Z_2 = {(), (1 2)}; its kernel is the even part of G |

### Subgroups and cosets

| Function | Result |
|---|---|
| `pgrp_subgroup(G, gens)` | the subgroup generated by `gens` |
| `pgrp_subgroups(G)` | every subgroup, smallest first |
| `pgrp_centraliser(G, A)`, `pgrp_normaliser(G, H)`, `pgrp_centre(G)` | C_G(A), N_G(H), Z(G); A is a list of permutations or a group |
| `pgrp_abelian_p(G)`, `pgrp_cyclic_p(G)` | whether G is abelian; cyclic |
| `pgrp_left_cosets(G, H)`, `pgrp_right_cosets(G, H)` | the cosets xH or Hx, each sorted, in order of their least elements |
| `pgrp_index(G, H)` | [G : H] |

### Quotients and conjugacy

| Function | Result |
|---|---|
| `pgrp_quotient(G, N)` | G/N as G acting on the left cosets of N; point i is the i-th coset of `pgrp_left_cosets(G, N)` |
| `pgrp_quotient_hom(G, N)` | the map from G onto `pgrp_quotient(G, N)` |
| `pgrp_conjugacy_classes(G)`, `pgrp_conjugacy_class(G, x)` | the classes (identity's first); the class of x |
| `pgrp_normal_subgroups(G)`, `pgrp_normal_closure(G, S)` | every normal subgroup; the smallest one containing S |
| `pgrp_simple_p(G)` | whether G is simple |

### Series, Sylow subgroups and products

| Function | Result |
|---|---|
| `pgrp_derived_subgroup(G)`, `pgrp_derived_series(G)`, `pgrp_solvable_p(G)` | G' = [G, G]; G, G', G'', ...; whether that reaches 1 |
| `pgrp_lower_central_series(G)`, `pgrp_nilpotent_p(G)` | G, [G, G], [[G, G], G], ...; whether that reaches 1 |
| `pgrp_composition_series(G)` | G = G_0 > G_1 > ... > 1 with simple quotients |
| `pgrp_sylow(G, p)`, `pgrp_sylow_subgroups(G, p)`, `pgrp_sylow_count(G, p)` | a Sylow p-subgroup; all of them; n_p |
| `pgrp_direct_product(G, H)` | G × H on disjoint points |
| `pgrp_abelian_invariants(G)` | invariant factors [d_1, d_2, ...], d_1 \| d_2 \| ..., of an abelian group |
| `pgrp_abelian_groups(n)` | every abelian group of order n, as lists of invariant factors |
| `pgrp_stabiliser_chain(G)` | the Schreier–Sims chain as [k, orbit] pairs; the orbit sizes multiply to the order |

Conjugates are g x g⁻¹ and commutators are [x, y] = x⁻¹y⁻¹xy, as in D&F.

## Example

```maxima
(%i1) load("permutations")$
(%i2) S4 : pgrp([2,1,3,4], [2,3,4,1]);
(%o2)            pgrp(degree 4, 2 generators)
(%i3) A4 : pgrp([2,3,1,4], [1,3,4,2])$
(%i4) [pgrp_order(S4), pgrp_order(A4), pgrp_normal_p(A4, S4)];
(%o4)                    [24, 12, true]
(%i5) pgrp_member_p(A4, pgrp_from_cycles([[1,2]]));
(%o5)                         false
(%i6) pgrp_generators(A4);
(%o6)                    [(1 2 3), (2 3 4)]
```

The tests also build the Rubik's cube group from cl-permutation's README
and check its order, 43252003274489856000.

## Not yet

- Block systems and factoring elements into generators, which cl-permutation
  has. Its `perm-compose s t` is also s∘t, so code built on it can use it
  directly.
- The structure functions list elements, so they stop at
  `pgrp_max_elements`. Large groups would need cl-permutation's algorithms
  or GAP.
- Character tables and the small-groups library.
