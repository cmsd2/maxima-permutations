## Cayley graphs

A Cayley graph draws a group: a vertex for each element, and an edge from g to g∘s for each generator s. `pgrp_cayley_graph` returns the graph as plain lists, so any plotting package can draw it. `pgrp_spectral_layout` places the vertices using the graph alone. For A_5 generated by an element of order 5 and one of order 2 whose product has order 3, the layout is the truncated icosahedron: a football, with the order-5 generator tracing its 12 pentagons.

### Function: pgrp_cayley_graph (G)

Returns the Cayley graph of `G` as `[n, edges]`.

Calling forms:

- `pgrp_cayley_graph(G)`: for the generators `pgrp_generators(G)`
- `pgrp_cayley_graph(G, gens)`: for the permutations in the list `gens`, which must be elements of `G`

Vertex i is the i-th element of `pgrp_elements(G)`. Each edge is `[i, j, k]`: generator k takes vertex i to vertex j, so element j is g_i∘s_k (apply s_k, then g_i). A generator of order 2 gives each edge once, with i < j, since s takes j back to i. An identity generator adds no edges. Generators that don't generate `G` give a graph in several pieces.

#### Examples

```maxima
(%i1) A5 : pgrp([2,3,4,5,1], [2,1,4,3,5])$
(%i2) C : pgrp_cayley_graph(A5)$
(%i3) [C[1], length(C[2])];
(%o3) [60, 90]
(%i4) map(lambda([k], length(sublist(C[2], lambda([e], e[3] = k)))), [1, 2]);
(%o4) [60, 30]
```

See also: `pgrp_spectral_layout`, `pgrp_elements`, `pgrp_cayley_table`

### Function: pgrp_spectral_layout (C)

Returns a point for each vertex of the graph `C`, from the eigenvectors of its Laplacian.

Calling forms:

- `pgrp_spectral_layout(C)`: points in 3 dimensions
- `pgrp_spectral_layout(C, dim)`: points in `dim` dimensions

`C` is `[n, edges]`, as `pgrp_cayley_graph` returns, with edges `[i, j]` or `[i, j, k]`. The coordinates of vertex i are the i-th entries of the eigenvectors for the `dim` lowest eigenvalues above zero. The points are scaled so the furthest is 1 from the origin; their rotation is arbitrary.

For a Cayley graph each eigenspace is a sum of copies of an irreducible representation, so the layout puts the vertices on an orbit of the group acting by rotations and the picture shows the group's symmetry. When eigenvalues repeat, `dim` must take all of a repeated eigenvalue or none, or the layout would rest on an arbitrary choice of vectors; the error lists the sizes allowed. A graph in several pieces is refused.

The work grows as the cube of the number of vertices: A_6, with 360, takes about ten seconds.

#### Examples

```maxima
(%i1) A5 : pgrp([2,3,4,5,1], [2,1,4,3,5])$
(%i2) P : pgrp_spectral_layout(pgrp_cayley_graph(A5))$
(%i3) /* every point is on the unit sphere */
      [length(P), every(lambda([p], is(abs(p . p - 1) < 1e-9)), P)];
(%o3) [60, true]
(%i4) pgrp_spectral_layout(pgrp_cayley_graph(A5), 2);
pgrp_spectral_layout: the lowest eigenvalues above zero come in groups of
               [3, 5, 3, 4, 9, 5], so dim must be one of [3, 8, 11, 15, 24, 29]
```

With ax-plots, `ax_graph` draws the result:

```maxima
(%i5) load("ax-plots")$
(%i6) C : pgrp_cayley_graph(A5)$
(%i7) ax_draw3d(ax_graph(pgrp_spectral_layout(C), C, edge_colors = ["#1f2440", "#e0452b"]))$
```

See also: `pgrp_cayley_graph`, `pgrp_spectral_max_vertices`

### Variable: pgrp_spectral_max_vertices

Default value: 1000. The largest graph that `pgrp_spectral_layout` will lay out.

See also: `pgrp_spectral_layout`
