## Groups

A group is given by generators. `pgrp_order` and `pgrp_member_p` use cl-permutation's Schreier–Sims implementation, so they work on very large groups. Functions that list a group's elements refuse groups with more than `pgrp_max_elements` elements.

### Function: pgrp (p_1, ..., p_k)

Returns the permutation group generated by the permutations `p_1`, ..., `p_k`.

Calling forms:

- `pgrp(p_1, ..., p_k)`
- `pgrp([p_1, ..., p_k])`: the same, with the generators in one list

The generators may be `pgrp_perm` values or lists of images, of any degrees; the group's degree is the largest. A group displays as `pgrp(degree n, k generators)`.

#### Examples

```maxima
(%i1) S4 : pgrp(pgrp_from_cycles([[1, 2]]), pgrp_from_cycles([[1, 2, 3, 4]]));
(%o1) pgrp(degree 4, 2 generators)
(%i2) pgrp_order(S4);
(%o2) 24
```

See also: `pgrp_generators`, `pgrp_subgroup`

### Function: pgrp_p (x)

Returns `true` if `x` is a permutation group.

#### Examples

```maxima
(%i1) [pgrp_p(pgrp_symmetric(3)), pgrp_p(pgrp_perm([2, 1]))];
(%o1) [true, false]
```

See also: `pgrp_perm_p`, `pgrp_hom_p`

### Function: pgrp_degree (x)

Returns the number of points a group or a permutation acts on.

#### Examples

```maxima
(%i1) [pgrp_degree(pgrp_dihedral(5)), pgrp_degree(pgrp_from_cycles([[1, 2]], 4)), pgrp_degree([2, 1, 3])];
(%o1) [5, 4, 3]
```

See also: `pgrp_order`

### Function: pgrp_generators (G)

Returns the generators of `G`, padded to its degree.

#### Examples

```maxima
(%i1) pgrp_generators(pgrp(pgrp_from_cycles([[1, 2]]), pgrp_from_cycles([[3, 4]])));
(%o1) [(1 2), (3 4)]
```

See also: `pgrp`

### Function: pgrp_order (G)

Returns the number of elements of `G`.

It doesn't list the elements, so it works on groups far too big to list.

#### Examples

```maxima
(%i1) pgrp_order(pgrp_symmetric(20));
(%o1) 2432902008176640000
```

See also: `pgrp_elements`, `pgrp_stabiliser_chain`

### Function: pgrp_member_p (G, p)

Returns `true` if the permutation `p` is in `G`.

Like `pgrp_order`, it works on groups too big to list.

#### Examples

```maxima
(%i1) A4 : pgrp_alternating(4)$
(%i2) [pgrp_member_p(A4, pgrp_from_cycles([[1, 2, 3]])), pgrp_member_p(A4, pgrp_from_cycles([[1, 2]]))];
(%o2) [true, false]
```

See also: `pgrp_subgroup_p`

### Function: pgrp_subgroup_p (H, G)

Returns `true` if `H` is a subgroup of `G`.

#### Examples

```maxima
(%i1) pgrp_subgroup_p(pgrp_alternating(4), pgrp_symmetric(4));
(%o1) true
```

See also: `pgrp_normal_p`, `pgrp_member_p`

### Function: pgrp_normal_p (H, G)

Returns `true` if `H` is a normal subgroup of `G`.

#### Examples

```maxima
(%i1) S4 : pgrp_symmetric(4)$
(%i2) [pgrp_normal_p(pgrp_alternating(4), S4), pgrp_normal_p(pgrp(pgrp_from_cycles([[1, 2]])), S4)];
(%o2) [true, false]
```

See also: `pgrp_subgroup_p`, `pgrp_normal_subgroups`

### Function: pgrp_orbits (G)

Returns the orbits of `G` on its points, each sorted, in order of their least points.

#### Examples

```maxima
(%i1) pgrp_orbits(pgrp(pgrp_from_cycles([[1, 2]]), pgrp_from_cycles([[3, 4, 5]])));
(%o1) [[1, 2], [3, 4, 5]]
```

See also: `pgrp_orbit`, `pgrp_stabiliser`

### Function: pgrp_random (G)

Returns a uniformly random element of `G`.

#### Examples

```maxima
(%i1) G : pgrp_symmetric(5)$
(%i2) pgrp_member_p(G, pgrp_random(G));
(%o2) true
```

See also: `pgrp_elements`

### Function: pgrp_elements (G)

Returns every element of `G`, in order of their lists of images.

Fails for groups with more than `pgrp_max_elements` elements.

#### Examples

```maxima
(%i1) pgrp_elements(pgrp_symmetric(3));
(%o1) [(), (2 3), (1 2), (1 2 3), (1 3 2), (1 3)]
```

See also: `pgrp_order`, `pgrp_max_elements`

### Function: pgrp_cayley_table (G)

Returns the Cayley table of a group, or of a list of permutations, as a matrix.

Calling forms:

- `pgrp_cayley_table(G)`: the elements of `G` in `pgrp_elements` order, labelled 1, 2, ...
- `pgrp_cayley_table(l)`: the permutations in the list `l`, labelled 1, 2, ...
- `pgrp_cayley_table(G, labels)`, `pgrp_cayley_table(l, labels)`: with the labels given

Row a, column b holds a∘b. Fails if a list isn't closed under composition.

#### Examples

```maxima
(%i1) pgrp_cayley_table(pgrp_cyclic(3), ["e", "r", "r^2"]);
      [  ∘    e    r   r^2 ]
      [                    ]
      [  e    e    r   r^2 ]
(%o1) [                    ]
      [  r    r   r^2   e  ]
      [                    ]
      [ r^2  r^2   e    r  ]
```

See also: `pgrp_elements`, `pgrp_compose`

### Variable: pgrp_max_elements

Default value: 100000. The largest group that the functions which list elements will handle.

Most structure functions work by listing a group's elements, so they refuse larger groups. `pgrp_order`, `pgrp_member_p`, `pgrp_orbits` and `pgrp_stabiliser_chain` don't list elements and work on any size.

#### Examples

```maxima
(%i1) pgrp_max_elements : 100$
(%i2) errcatch(pgrp_elements(pgrp_symmetric(5)));
pgrp_elements: the group has 120 elements, more than pgrp_max_elements = 100
(%o2) []
```

See also: `pgrp_elements`, `pgrp_order`
