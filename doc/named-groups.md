## Named groups

The standard small groups, each as a permutation group with fixed generators.

### Function: pgrp_cyclic (n)

Returns the cyclic group Z_n, generated by (1 2 ... n).

#### Examples

```maxima
(%i1) Z6 : pgrp_cyclic(6)$
(%i2) [pgrp_order(Z6), pgrp_generators(Z6)];
(%o2) [6, [(1 2 3 4 5 6)]]
```

See also: `pgrp_cyclic_p`, `pgrp_dihedral`

### Function: pgrp_dihedral (n)

Returns the dihedral group D_2n of order 2n, the symmetries of a regular n-gon.

The vertices are 1, ..., n in order. The generators are r = (1 2 ... n), the rotation sending i to i + 1, and s, the reflection fixing vertex 1, as in Dummit and Foote §1.2. `n` must be at least 3.

#### Examples

```maxima
(%i1) D8 : pgrp_dihedral(4)$
(%i2) [pgrp_order(D8), pgrp_generators(D8)];
(%o2) [8, [(1 2 3 4), (2 4)]]
```

See also: `pgrp_cyclic`, `pgrp_symmetric`

### Function: pgrp_symmetric (n)

Returns the symmetric group S_n, generated by (1 2) and (1 2 ... n).

#### Examples

```maxima
(%i1) makelist(pgrp_order(pgrp_symmetric(n)), n, 1, 6);
(%o1) [1, 2, 6, 24, 120, 720]
```

See also: `pgrp_alternating`

### Function: pgrp_alternating (n)

Returns the alternating group A_n, the even permutations of 1, ..., n.

It is generated by the 3-cycles (1 2 k) for k = 3, ..., n.

#### Examples

```maxima
(%i1) [pgrp_order(pgrp_alternating(5)), pgrp_simple_p(pgrp_alternating(5))];
(%o1) [60, true]
```

See also: `pgrp_symmetric`, `pgrp_sign`

### Function: pgrp_quaternion ()

Returns the quaternion group Q_8, acting on itself by left multiplication.

Points 1, ..., 8 stand for 1, -1, i, -i, j, -j, k, -k, and the generators are i and j. An element g sends the point 1 to the point that names g.

#### Examples

```maxima
(%i1) Q8 : pgrp_quaternion()$
(%i2) [pgrp_order(Q8), pgrp_order_profile(Q8)];
(%o2) [8, [[1, 1], [2, 1], [4, 6]]]
```

See also: `pgrp_dihedral`, `pgrp_isomorphic_p`
