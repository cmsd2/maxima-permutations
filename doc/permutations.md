# Package permutations

## Introduction to permutations

The `permutations` package adds permutation groups to Maxima, built on Robert Smith's [cl-permutation](https://github.com/stylewarning/cl-permutation). Maxima's `combinatorics` package works on single permutations. This package adds groups: order and membership by Schreier–Sims, subgroups and cosets, homomorphisms and quotients, conjugacy classes, Sylow subgroups, series, actions and counting.

**Requirements:** SBCL (Steel Bank Common Lisp). `mxpm install` fetches cl-permutation through Quicklisp.

### Quick start

```maxima
(%i1) S4 : pgrp_symmetric(4);
(%o1) pgrp(degree 4, 2 generators)
(%i2) A4 : pgrp_alternating(4)$
(%i3) [pgrp_order(S4), pgrp_order(A4), pgrp_normal_p(A4, S4)];
(%o3) [24, 12, true]
(%i4) r : pgrp_from_cycles([[1, 2, 3, 4]])$
(%i5) s : pgrp_from_cycles([[2, 4]])$
(%i6) [pgrp_compose(r, s), pgrp_compose(s, r)];
(%o6) [(1 2)(3 4), (1 4)(2 3)]
(%i7) pgrp_member_p(A4, r);
(%o7) false
(%i8) pgrp_elements(pgrp_centre(pgrp_dihedral(4)));
(%o8) [(), (1 3)(2 4)]
```

### Permutations

Results that are permutations come back as `pgrp_perm` values, shown in cycle notation, with `()` for the identity. Every function also accepts a list of images, the form the `combinatorics` package uses: `[2,1,3]` maps 1 to 2, 2 to 1 and 3 to 3. A permutation value keeps its degree, so (1 2) in S_4 has cycle type [2, 1, 1]. Equal permutations of the same degree are the same value, so `=`, `member`, `unique` and `setify` work on them; `pgrp_eq` compares across degrees. Set `pgrp_perm_output : false` to get lists of images back.

### Conventions

These follow Dummit and Foote, *Abstract Algebra*.

- Composition reads right to left: `pgrp_compose(s, t)` is s∘t, which applies `t` first. The `combinatorics` package's `permult` reads the other way.
- D_2n is the dihedral group of order 2n, generated by r = (1 2 ... n) and s, the reflection fixing vertex 1.
- Conjugates are g x g^-1, and commutators are [x, y] = x^-1 y^-1 x y.
- Actions are on the left, and `pgrp_quotient` uses left cosets.

### Limits

Most structure functions list a group's elements, so they refuse groups with more than `pgrp_max_elements` elements (100000 by default). `pgrp_order`, `pgrp_member_p`, `pgrp_orbits` and `pgrp_stabiliser_chain` don't list elements and work on groups of any size, such as the Rubik's cube group of order 43252003274489856000.
