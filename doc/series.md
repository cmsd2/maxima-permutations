## Series, Sylow subgroups and products

Series of subgroups, the Sylow subgroups, direct products and abelian groups. Except for `pgrp_stabiliser_chain`, these functions list elements, so they are limited by `pgrp_max_elements`.

### Function: pgrp_derived_subgroup (G)

Returns the derived subgroup G' = [G, G], generated by all commutators.

It is the smallest normal subgroup with an abelian quotient.

#### Examples

```maxima
(%i1) pgrp_isomorphic_p(pgrp_derived_subgroup(pgrp_symmetric(4)), pgrp_alternating(4));
(%o1) true
```

See also: `pgrp_derived_series`, `pgrp_commutator`

### Function: pgrp_derived_series (G)

Returns the derived series G, G', G'', ..., until it stops getting smaller.

#### Examples

```maxima
(%i1) map(pgrp_order, pgrp_derived_series(pgrp_symmetric(4)));
(%o1) [24, 12, 4, 1]
```

See also: `pgrp_derived_subgroup`, `pgrp_solvable_p`

### Function: pgrp_solvable_p (G)

Returns `true` if the derived series of `G` reaches the trivial group.

#### Examples

```maxima
(%i1) [pgrp_solvable_p(pgrp_symmetric(4)), pgrp_solvable_p(pgrp_symmetric(5))];
(%o1) [true, false]
```

See also: `pgrp_derived_series`, `pgrp_nilpotent_p`

### Function: pgrp_lower_central_series (G)

Returns the lower central series G, [G, G], [[G, G], G], ..., until it stops getting smaller.

#### Examples

```maxima
(%i1) map(pgrp_order, pgrp_lower_central_series(pgrp_dihedral(8)));
(%o1) [16, 4, 2, 1]
```

See also: `pgrp_nilpotent_p`, `pgrp_derived_series`

### Function: pgrp_nilpotent_p (G)

Returns `true` if the lower central series of `G` reaches the trivial group.

#### Examples

```maxima
(%i1) [pgrp_nilpotent_p(pgrp_dihedral(4)), pgrp_nilpotent_p(pgrp_symmetric(3))];
(%o1) [true, false]
```

See also: `pgrp_lower_central_series`, `pgrp_solvable_p`

### Function: pgrp_composition_series (G)

Returns a composition series G = G_0 > G_1 > ... > 1, each a normal subgroup of the one before with a simple quotient.

Each step takes a largest proper normal subgroup, which lists elements, so keep `G` small.

#### Examples

```maxima
(%i1) map(pgrp_order, pgrp_composition_series(pgrp_symmetric(4)));
(%o1) [24, 12, 4, 2, 1]
```

See also: `pgrp_simple_p`, `pgrp_quotient`

### Function: pgrp_sylow (G, p)

Returns a Sylow `p`-subgroup of `G`.

If the order of `G` is p^a m with `p` not dividing m, it has order p^a.

#### Examples

```maxima
(%i1) pgrp_order(pgrp_sylow(pgrp_symmetric(4), 2));
(%o1) 8
```

See also: `pgrp_sylow_subgroups`, `pgrp_sylow_count`

### Function: pgrp_sylow_subgroups (G, p)

Returns every Sylow `p`-subgroup of `G`.

#### Examples

```maxima
(%i1) map(pgrp_elements, pgrp_sylow_subgroups(pgrp_symmetric(3), 2));
(%o1) [[(), (2 3)], [(), (1 3)], [(), (1 2)]]
```

See also: `pgrp_sylow`, `pgrp_sylow_count`

### Function: pgrp_sylow_count (G, p)

Returns n_p, the number of Sylow `p`-subgroups of `G`.

#### Examples

```maxima
(%i1) A5 : pgrp_alternating(5)$
(%i2) makelist([p, pgrp_sylow_count(A5, p)], p, [2, 3, 5]);
(%o2) [[2, 5], [3, 10], [5, 6]]
```

See also: `pgrp_sylow_subgroups`

### Function: pgrp_direct_product (G, H)

Returns the direct product G x H, with `G` on the first points and `H` on the points after them.

#### Examples

```maxima
(%i1) P : pgrp_direct_product(pgrp_cyclic(2), pgrp_cyclic(3))$
(%i2) [pgrp_degree(P), pgrp_order(P), pgrp_generators(P)];
(%o2) [5, 6, [(1 2), (3 4 5)]]
```

See also: `pgrp_abelian_invariants`

### Function: pgrp_abelian_invariants (G)

Returns the invariant factors [d_1, d_2, ...] of an abelian group `G`, with each d_i dividing the next.

`G` is isomorphic to Z_d1 x Z_d2 x .... The trivial group gives `[]`. Fails if `G` isn't abelian.

#### Examples

```maxima
(%i1) pgrp_abelian_invariants(pgrp_direct_product(pgrp_cyclic(4), pgrp_cyclic(6)));
(%o1) [2, 12]
```

See also: `pgrp_abelian_groups`, `pgrp_abelian_p`

### Function: pgrp_abelian_groups (n)

Returns every abelian group of order `n`, as lists of invariant factors.

#### Examples

```maxima
(%i1) pgrp_abelian_groups(36);
(%o1) [[2, 18], [3, 12], [6, 6], [36]]
```

See also: `pgrp_abelian_invariants`

### Function: pgrp_stabiliser_chain (G)

Returns the Schreier–Sims stabiliser chain of `G` as `[k, orbit]` pairs.

Each pair is a point k and its orbit under the subgroup that fixes every point above k. The orbit sizes multiply to the order of `G`. It doesn't list elements, so it works on large groups.

#### Examples

```maxima
(%i1) chain : pgrp_stabiliser_chain(pgrp_symmetric(4));
(%o1) [[4, [1, 2, 3, 4]], [3, [1, 2, 3]], [2, [1, 2]]]
(%i2) apply("*", map(lambda([lev], length(lev[2])), chain));
(%o2) 24
```

See also: `pgrp_order`, `pgrp_stabiliser`
