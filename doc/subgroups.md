## Subgroups and cosets

Subgroups are permutation groups of the same degree as the group they came from. Cosets are lists of permutations.

### Function: pgrp_subgroup (G, gens)

Returns the subgroup of `G` generated by the permutations in the list `gens`.

Fails if a generator is not in `G`. The subgroup keeps the degree of `G`.

#### Examples

```maxima
(%i1) H : pgrp_subgroup(pgrp_symmetric(4), [pgrp_from_cycles([[1, 2, 3, 4]])])$
(%i2) [pgrp_order(H), pgrp_degree(H)];
(%o2) [4, 4]
```

See also: `pgrp`, `pgrp_subgroups`

### Function: pgrp_subgroups (G)

Returns every subgroup of `G`, smallest first.

#### Examples

```maxima
(%i1) map(pgrp_order, pgrp_subgroups(pgrp_dihedral(4)));
(%o1) [1, 2, 2, 2, 2, 2, 4, 4, 4, 8]
```

See also: `pgrp_normal_subgroups`, `pgrp_subgroup`

### Function: pgrp_centraliser (G, A)

Returns the centraliser C_G(A), the elements of `G` that commute with every permutation in `A`.

`A` is a list of permutations or a group.

#### Examples

```maxima
(%i1) pgrp_elements(pgrp_centraliser(pgrp_symmetric(4), [pgrp_from_cycles([[1, 2]], 4)]));
(%o1) [(), (3 4), (1 2), (1 2)(3 4)]
```

See also: `pgrp_centre`, `pgrp_normaliser`

### Function: pgrp_normaliser (G, H)

Returns the normaliser N_G(H), the elements g of `G` with g H g^-1 = H.

#### Examples

```maxima
(%i1) S4 : pgrp_symmetric(4)$
(%i2) pgrp_elements(pgrp_normaliser(S4, pgrp_subgroup(S4, [pgrp_from_cycles([[1, 2]], 4)])));
(%o2) [(), (3 4), (1 2), (1 2)(3 4)]
```

See also: `pgrp_centraliser`, `pgrp_normal_p`

### Function: pgrp_centre (G)

Returns the centre Z(G), the elements that commute with every element of `G`.

#### Examples

```maxima
(%i1) pgrp_elements(pgrp_centre(pgrp_dihedral(4)));
(%o1) [(), (1 3)(2 4)]
```

See also: `pgrp_centraliser`, `pgrp_abelian_p`

### Function: pgrp_abelian_p (G)

Returns `true` if `G` is abelian.

#### Examples

```maxima
(%i1) [pgrp_abelian_p(pgrp_cyclic(6)), pgrp_abelian_p(pgrp_symmetric(3))];
(%o1) [true, false]
```

See also: `pgrp_cyclic_p`, `pgrp_centre`

### Function: pgrp_cyclic_p (G)

Returns `true` if `G` is cyclic.

#### Examples

```maxima
(%i1) [pgrp_cyclic_p(pgrp_direct_product(pgrp_cyclic(2), pgrp_cyclic(3))), pgrp_cyclic_p(pgrp_direct_product(pgrp_cyclic(2), pgrp_cyclic(2)))];
(%o1) [true, false]
```

See also: `pgrp_abelian_p`, `pgrp_cyclic`

### Function: pgrp_left_cosets (G, H)

Returns the left cosets gH of `H` in `G`.

Each coset is sorted, and the cosets come in order of their least elements, so two such lists are equal exactly when the cosets are.

#### Examples

```maxima
(%i1) pgrp_left_cosets(pgrp_symmetric(3), pgrp(pgrp_from_cycles([[1, 2]], 3)));
(%o1) [[(), (1 2)], [(2 3), (1 3 2)], [(1 2 3), (1 3)]]
```

See also: `pgrp_right_cosets`, `pgrp_index`, `pgrp_quotient`

### Function: pgrp_right_cosets (G, H)

Returns the right cosets Hg of `H` in `G`.

Sorted as in `pgrp_left_cosets`. For a subgroup that isn't normal, the right cosets differ from the left ones.

#### Examples

```maxima
(%i1) pgrp_right_cosets(pgrp_symmetric(3), pgrp(pgrp_from_cycles([[1, 2]], 3)));
(%o1) [[(), (1 2)], [(2 3), (1 2 3)], [(1 3 2), (1 3)]]
```

See also: `pgrp_left_cosets`

### Function: pgrp_index (G, H)

Returns the index [G : H], the number of cosets of `H` in `G`.

#### Examples

```maxima
(%i1) pgrp_index(pgrp_symmetric(4), pgrp_dihedral(4));
(%o1) 3
```

See also: `pgrp_left_cosets`
